# Contributing to ScholarGraph AI

Thank you for your interest in contributing. This project welcomes contributions that improve academic usefulness, code quality, documentation, and reproducibility.

## Good first contributions

- Improve README explanations.
- Add sample papers or literature matrix examples.
- Improve frontend accessibility and responsiveness.
- Add backend tests.
- Improve gap-detection heuristics.
- Add export templates for Markdown, CSV, or PDF.

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Test the frontend or backend locally.
5. Open a pull request with a clear explanation.

## Academic quality expectations

Because this project is designed for research workflows, contributors should avoid unsupported claims. Any documentation about research practice should be written carefully and should distinguish between implemented features, planned features, and conceptual ideas.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] The code is readable and documented where necessary.
- [ ] The README or docs are updated if behavior changes.
- [ ] The change does not include private PDFs, copyrighted papers, or personal research data.
- [ ] AI-generated outputs are clearly identified as suggestions, not verified scholarship.
