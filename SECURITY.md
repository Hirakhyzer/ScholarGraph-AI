# Security Policy

ScholarGraph AI is a research prototype. Users should treat uploaded research papers, unpublished thesis drafts, and supervisor notes as sensitive data.

## Current security status

The current repository does not include authentication, cloud storage, or production deployment configuration. It is intended for local development and demonstration.

## Data handling guidance

- Do not commit copyrighted PDFs or private research files.
- Do not commit thesis drafts, unpublished manuscripts, or participant data.
- Do not upload personally identifiable information to public demos.
- Use local sample data for testing.

## Reporting vulnerabilities

Please open a GitHub issue for non-sensitive security improvements. For sensitive reports, contact the maintainer privately if contact details are available on the GitHub profile.

## Future security roadmap

- Authentication and workspace permissions.
- File access controls.
- Secure temporary upload storage.
- Redaction of sensitive metadata.
- Audit log for AI-generated research outputs.
