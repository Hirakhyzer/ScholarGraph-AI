# ScholarGraph AI Frontend

This frontend is a polished React/Vite concept dashboard for the ScholarGraph AI research intelligence platform.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Current UI sections

- Sidebar navigation for research modules.
- Hero section explaining the PhD research workflow.
- Metric cards for papers, topic clusters, gap signals, and thesis readiness.
- Knowledge graph concept visualization.
- Research gap signal panel.
- Literature review matrix table.
