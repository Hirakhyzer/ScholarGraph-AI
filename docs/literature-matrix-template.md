# Literature Review Matrix Template

Use this template to organize papers before entering them into ScholarGraph AI.

| Field | Notes |
|---|---|
| Full citation | APA/IEEE/ACM citation |
| Research problem | What problem does the paper address? |
| Research question | What question does the paper try to answer? |
| Theory or framework | Which theory, model, or conceptual framework is used? |
| Methodology | Survey, experiment, model, case study, qualitative, quantitative, mixed-method, etc. |
| Dataset / participants | Dataset name, sample size, corpus, benchmark, population, or context |
| Evaluation metrics | Accuracy, F1, RMSE, thematic validity, user feedback, etc. |
| Main findings | Key results and contributions |
| Limitations | Weaknesses, threats to validity, missing evaluations |
| Future work | Directions proposed by the authors |
| Gap signal | What unresolved issue does this paper reveal? |
| Relevance to thesis | High / medium / low, with reason |
| Notes | Your own critical reflection |
