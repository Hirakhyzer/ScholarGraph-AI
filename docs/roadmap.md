# Product and Research Roadmap

ScholarGraph AI is planned as a staged project that can evolve from a polished prototype into a serious research software platform.

## Phase 1 — Repository Foundation

Status: complete.

- Create professional GitHub repository structure.
- Add attractive README and visual assets.
- Add FastAPI backend scaffold.
- Add React dashboard scaffold.
- Add architecture and methodology documentation.

## Phase 2 — Runnable Research Prototype

Goal: support manual paper entry and structured analysis.

- Add form-based paper entry in the frontend.
- Connect frontend to `/analyze/paper` backend endpoint.
- Display returned themes, methods, gaps, and research questions.
- Export analysis as Markdown.
- Add local sample dataset.

## Phase 3 — PDF Intelligence

Goal: support real paper upload and extraction.

- Add PDF upload endpoint.
- Extract title, abstract, section headings, references, and author metadata.
- Detect methodology and limitations sections.
- Store extracted text in a local database.
- Create a paper quality report.

## Phase 4 — Knowledge Graph Engine

Goal: build visual and analytical relationships across papers.

- Add graph generation from multiple papers.
- Add topic clustering.
- Add method-dataset mapping.
- Add limitation-to-gap mapping.
- Add graph centrality and cluster summaries.
- Add React Flow or D3 visualization.

## Phase 5 — PhD Literature Review Tools

Goal: support thesis and dissertation workflows.

- Generate literature review matrix.
- Generate annotated bibliography.
- Generate gap justification draft.
- Generate research question candidates.
- Generate dissertation chapter outline.
- Generate supervisor meeting summary.

## Phase 6 — Evaluation and Academic Rigor

Goal: make outputs auditable and research-worthy.

- Add evaluation dataset.
- Add human annotation protocol.
- Add precision/recall metrics for extraction.
- Add citation traceability.
- Add reproducibility report.
- Publish system limitations clearly.

## Phase 7 — Advanced AI Layer

Goal: support explainable, source-grounded AI assistance.

- Add embeddings for semantic paper retrieval.
- Add local or API-based LLM support.
- Add source-grounded answer generation.
- Add contradiction detection across papers.
- Add novelty and contribution analysis.
- Add transparent confidence indicators.

## Long-term vision

ScholarGraph AI should become a research companion for doctoral students: a tool that helps them convert overwhelming literature into a structured, defensible, and academically rigorous research plan.
